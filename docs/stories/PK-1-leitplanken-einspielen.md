**Art:** Technik · **Priorität:** Mittel · **Systeme:** Online-Banking

## Story

Als Haus möchten wir, dass jedes System die Leitplanken in docs/leitplanken.md trägt, damit der Coding-Agent sie beim Lesen von docs/ findet. KnippQAi schreibt die Datei, sobald die Leitplanken geändert werden; fertig, wenn der Pull Request gemergt ist.
